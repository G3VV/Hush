Fleet analytics

—

How this is measured. Dott rotates each vehicle's ID after every rental — the GBFS spec asks operators to, so riders can't be followed between trips. A vehicle that leaves the feed never comes back under the same ID, so individual journeys can't be reconstructed and aren't shown here. What is directly observable: a rental starting (a vehicle leaves the feed) and a rental ending (a new ID appears). Ride duration is derived from those counts by Little's Law rather than measured per vehicle, and the number out riding is the shortfall against the largest fleet ever seen available — so both need about half a day of collecting, including one overnight lull, before they mean anything.

Public transport

—

Where this comes from. Live bus and coach positions are the DfT's Bus Open Data Service national GTFS-Realtime feed, clipped to Bristol — no API key needed. Operators leave dead vehicles in the feed for hours, so anything whose last report is over 15 minutes old is dropped rather than drawn as a phantom bus. Bus fleet numbers are stable, unlike the scooters, so these vehicles are tracked properly and each one has a real recorded trail. Live train positions are not included — every UK source for them (Network Rail, Darwin, Realtime Trains) requires a registered account, so rail appears as stations only.

Rail

—

Timings, not positions. Realtime Trains returns when services call where, with live forecasts, delays, platforms and cancellations — but no coordinates anywhere, in either the service data or the reference data. So trains are not drawn as moving markers. Each station is live instead: click one on the map for its real board. Station coordinates come from OpenStreetMap, matched to RTT codes by name.
